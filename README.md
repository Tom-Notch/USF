Unified Spherical Frontend (USF) is a distortion-free lens-agnostic rotation-equivariant vision framework for modern perception

## Usage

1. Make sure `nodejs` is available either by system install or conda install

1. `npm install`

1. `npm run dev`

## Features

- Auto-theme for background video and images
- Adapt to all devices
- Interactive experience with clickable framework diagram and models
